# DynCombo — Odoo Apps

Publishing repository for the Odoo Apps store. One folder per app at the repo
root; the branch name matches the Odoo series (**18.0**).

## Demo

[![Watch the DynCombo demo](https://img.youtube.com/vi/II9c4IAfR6U/hqdefault.jpg)](https://youtu.be/II9c4IAfR6U)

▶ **[Watch the feature walkthrough](https://youtu.be/II9c4IAfR6U)** — setup,
live pricing, combo discount, configurable combos, moving components between
combos, and printing.

## Apps
- **sale_dynamic_combo/** — DynCombo: dynamic kits & combos for sales
  (v18.0.5.12.4, OPL-1, commercial).

Development and tests live in the separate `odoo-lab` repo; this repo is the
store publishing target.
